# SEO and structured data

Each static page has localized title, description, canonical, Open Graph/Twitter metadata, H1 and reciprocal hreflang. Service content is unique for Florence rather than mass-generated doorway content. Internal links and breadcrumb structured data connect journeys; FAQ schema appears only with visible FAQ content.

Organization, Web/Service-adjacent, FAQ and breadcrumb vocabulary is used conservatively. Do not mark the business as a hospital, clinic, physician or pharmacy until legally approved. Set `PUBLIC_SITE_URL` in production to generate absolute canonicals and `sitemap.xml`; without it, no placeholder sitemap/domain is emitted. Review the generated sitemap and submit it in Search Console after domain verification.

The site uses minimal JavaScript, system fonts, intrinsic layout and static HTML. Run Lighthouse against production for performance, accessibility, best practices and SEO, then record results after final imagery and analytics consent are configured.
